## 4. Recommended builds for YOUR use case
**What Kimi Code / AI coding tools actually need:** the AI itself runs in the cloud — your machine needs a strong multicore CPU, LOTS of RAM (IDE + browser tabs + Docker + emulators), fast NVMe storage, and a reliable PSU. The GPU only matters if you want to experiment with local LLMs or game on the side.

### Tier 1 — Value (~65,000 EGP)
Cheapest sensible dev box, AM5 upgrade path:
Ryzen 5 7600 (8,800) + B650M (6,000) + 32GB DDR5 (19,000) + 1TB Gen4 (6,000) + RTX 5060 8GB (20,000) + 750W Bronze (3,100) + case (2,500)
*Cheaper variant: i5-14400F + DDR4 board saves ~10K but is a dead-end platform.*

### Tier 2 — Sweet spot ⭐ (~100–120K EGP) — main recommendation
Ryzen 7 9700X (14,500) + ASUS Prime B650M-A WiFi (7,800) + **64GB DDR5** (40,000) + 2TB Gen4 (12,000) + **RTX 5060 Ti 16GB** (35,000) + 750W Gold (4,300) + case + cooler (6,000) ≈ **119,600**
💡 **Budget valve: start with 32GB RAM (19,000) → total ~99K, add the second kit later when the RAM shortage eases.**
The 5060 Ti 16GB's VRAM beats the RTX 5070 12GB for local-LLM dabbling at the same money.

### Tier 3 — Serious local-LLM experimentation (~154K EGP)
Ryzen 7 9700X + TUF B650 (10,000) + 64GB DDR5 + 2TB + **RTX 5070 Ti 16GB** (63,000) + 850W Gold (5,750) + 240mm AIO
Highest VRAM-per-pound new card available in Egypt (RTX 5080 16GB costs 90K+ for no VRAM gain).

## 5. Key buying advice

1. **Prebuilt vs DIY is inverted in Egypt right now** — store bundles (Technology Valley 58K, CompuMarts 75K/110K) are priced at or *below* the sum of parts because some listings predate the RAM spike. Check bundles first, but verify the exact RAM speed, SSD model and PSU brand inside — that's where shops cut corners.
2. **RAM is the most inflated component in 2026.** Buy 64GB only if you truly need it now; otherwise 32GB + upgrade later.
3. **Avoid Amazon.eg for GPUs** — listings like RTX 5070 @ 98,999 are far above specialist-store prices (~34–48K).
4. **CPU choice:** Ryzen 7 9700X @ ~14.5K is the multicore value king (vs i7-14700F @ 17.5K on a dead socket). Ryzen 5 7600 @ ~8.8K is the budget pick.
5. **Payment flexibility:** AHW Store (valU + COD), East Asia (up to 60 months), 2B (installments), Noon (split payments). CompuMarts explicitly has **no installments**.
6. **Before buying:** cross-check any quote on eg-pc.com / hardwarehubeg.com / egprices.com, and confirm stock by WhatsApp — most stores list numbers and it's the norm in this market.
7. **Legitimacy signal:** Elnekhely, Sigma, ElBadr, CompuMarts, High End and Hankerz are all Antec-listed official Egyptian e-tailers.
